# Import Export Hub
Delivering Excellence Through Trusted Logistics Expertise

Comprehensive Logistics Solutions Tailored For You

🌍 **Import Export Hub** is a modern web platform where users can explore global products, manage exports, and import products into their personal dashboard with a single click. The application offers a clean UI, secure authentication, and real-time data synchronization.

## 🔗 Live Website
👉 https://chipper-donut-6bbd5b.netlify.app

👉 Server Site Repository: https://github.com/mahfujaakthermoury/import-export-hub-server-side

## 🚀 Features
- User authentication with Email/Password and Google login
- Browse all products and view detailed product information
- Import products with quantity validation and real-time stock updates
- Add, update, and delete export products (user-specific)
- Personalized dashboards for My Imports and My Exports
- Protected routes to ensure secure access to user data
- Responsive and modern user interface

## 🛠️ Technologies Used
- React
- React Router
- Firebase Authentication
- Node.js
- Express.js
- MongoDB
- Tailwind CSS / DaisyUI

## 🔒 Authentication
- Email & Password based login and registration
- Google social login
- No email verification or password reset (as per project requirement)

## 📦 Project Purpose
This project is built to demonstrate full-stack CRUD operations, authentication, protected routes, and real-world import/export workflow using modern web technologies.
